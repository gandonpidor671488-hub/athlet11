# ATHLET — магазин спортивного питания (.NET MAUI, C#, XAML)

## Запуск
1. Visual Studio 2022 (17.8+) → Installer → «Изменить» → рабочая нагрузка **«Разработка мобильных приложений на .NET»** (+ компонент Android SDK / эмулятор).
2. Файл → Открыть → Проект → `Athlet.csproj`.
3. Вверху выбрать **Android Emulator** (Tools → Android → Android Device Manager → создать Pixel, API 34) либо подключённый телефон (включить «Отладка по USB»).
4. **F5**. Первая сборка 3–10 минут (скачиваются пакеты).

Если установлена только .NET 9/10: в `Athlet.csproj` замените `net8.0-android` на `net9.0-android` / `net10.0-android`.

## Сборка в один файл (APK)
- Отладочный APK уже собирается при F5: `bin/Debug/net8.0-android/com.athlet.shop-Signed.apk`.
- Релизный: в терминале из папки проекта
  `dotnet publish -f net8.0-android -c Release`
  → `bin/Release/net8.0-android/publish/*.apk`. Для подписи: Build → Archive → Distribute → Ad Hoc (создаст keystore).
- Установка: скопировать .apk на телефон и открыть (разрешить «Установку из неизвестных источников»).

## Демо для защиты
- Промокоды: ATHLET10, FIT15 (от 3 000 ₽), WELCOME (от 1 500 ₽). В корзине их можно выбрать одним нажатием.
- Заказ: самовывоз готов через 1 день, курьер везёт 3 дня. В «Мои заказы» видно этапы, дни и часы до прибытия, трек-номер.
- Кнопка «Перемотать на 1 день (демо)» двигает время вперёд, чтобы показать смену этапов: принят, собирается, передан курьеру, в пути, доставлен.
- Получение заказа в пункте выдачи: когда самовывоз готов (или после «Перемотать на 1 день (демо)»), на главной появляется карточка «Успейте забрать». Она открывает экран с штрихкодом (Code 128), адресом пункта, суммой «К оплате», товарами, последним днём хранения (5 дней) и блоком «Добавьте в следующий заказ». Кнопка «Я получил заказ» закрывает заказ. Тот же экран открывается из «Мои заказы».
- Заказ можно отменить (пока он на этапах «принят» и «собирается») и повторить одним нажатием.
- Бонусы: 5% от суммы заказа возвращаются бонусами, при следующем заказе ими можно оплатить до 30% суммы.
- Фото товаров: на карточках сверху грузится тематическое фото из интернета (нужен интернет на телефоне). Если оно не загрузилось, видна нарисованная упаковка. В профиле есть переключатель «Фото товаров из интернета».
- Своё фото: в карточке товара внизу вставить ссылку на картинку и нажать «Применить фото».
- Если ставите поверх старой версии и установка не проходит, сначала удалите старое приложение ATHLET с телефона.

## Тест-план (таблица 3 записки)
1 запуск → 2 переходы по вкладкам → 3 каталог → 4 карточка → 5 «В корзину» → 6 +/− и пересчёт суммы → 7 заказ: пустое имя/телефон/адрес дают ошибку, корректные данные дают «Заказ №N оформлен».

## Сборка APK в облаке (без Visual Studio)
1. Создать бесплатный аккаунт на github.com, нажать New repository, имя `athlet`, Create.
2. Загрузить в репозиторий **содержимое** папки ATHLET (Add file → Upload files), чтобы `Athlet.csproj` лежал в корне.
3. Файл `.github/workflows/build.yml` создать вручную: Add file → Create new file, в имя ввести `.github/workflows/build.yml`, вставить содержимое из проекта, Commit.
4. Вкладка Actions → Build APK → дождаться зелёной галочки (5–10 мин) → внизу страницы раздел Artifacts → скачать `ATHLET-apk`.
5. Распаковать, скопировать `.apk` на Android-телефон и установить.
